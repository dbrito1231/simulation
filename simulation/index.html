              Proclamation (public, one-shot)

              Binding guidance. Agents with active providence must answer via divine_response (follow or continue + reason) on their next think. Proclamation also sets timed providence (same slot, duration, and revoke as Providence).

              Providence (public, cancellable)

              Binding guidance. Every agent must answer via divine_response (follow or continue + reason) while providence is active. Check adherence under Adherence below or in Sight.

              Private omen (one agent, cancellable)

              Binding guidance. The target agent must answer via divine_response (follow or continue + reason) while the omen is active. Omen text never appears in adherence logs — only the agent's stated reason.

              Whisper campaign (multi-agent, cancellable)

              Binding guidance. Each targeted agent must answer via divine_response (follow or continue + reason) for their whisper. Whisper text never appears in adherence logs.

              Adherence

              Village-wide log of how agents answered binding Voice guidance. Refreshes from Sight — private omen text is never shown, only each agent's stated reason.

              Matrix tools manipulate agent brains and environment via Preview → Apply. Most effects are private (not in public /state). Preview validates without changing the world; Apply commits the last successful preview. Hover any labeled control for more detail. Durations are simulation frames (~30 per second).

              Brain

              Brain / Temperature dial (cancellable)

              Change how creative or random one agent's decision model is — model, temperature, and optional sampling caps. Private; villagers never see it. Only one living agent may use sim-fast at a time.

              Revoke sampling override

              Remove an active temperature-dial override and restore the agent's default decision model.

              Memory

              Memory insert (IRREVERSIBLE)

              Plant a memory only that agent will recall in future think prompts. Cannot be removed except by targeted memory delete. Private — never appears in public logs.

              Memory delete (IRREVERSIBLE)

              Erase memories matching your filters from one agent's vector store. You must provide at least one filter (keyword, frame range, or kinds).

              Belief plant (IRREVERSIBLE)

              Give the agent a belief or tenet they will treat as their own. Use a known belief id or custom text. Private — never in public logs.

              Distortion

              Reality distortion / context mask (cancellable)

              Alter what one agent sees in their think snapshot before the LLM decides. Modes hide divine lines, reveal simulation truth, fabricate world state, or forge nearby chat. Private — never in public /state.

              Possession

              Decision compulsion (cancellable)

              Force a pinned action after the LLM runs — the model still thinks, but its output is overridden. Private; revoke via decision gate cancel.

              Thought veto — arm (cancellable)

              Hold the agent's next LLM decision for your review. The agent pauses until you resolve with approve, reject, or rewrite.

              Thought veto — resolve (IRREVERSIBLE)

              Resolve a held veto decision: approve what the LLM chose, reject it (fallback action), or rewrite to a different action.

              Agent possession (cancellable)

              Skip the LLM entirely and puppet one action each think cycle. Stronger than compulsion — no model call runs. Private; revoke via decision gate cancel.

              Revoke decision gate

              Clear any active compulsion, veto hold, or possession for one agent and restore normal LLM decisions.

              Dialogue & Bargain

              Burning Bush (private)

              Send a private God↔agent dialogue line. Only that agent sees the thread in their think context; it never appears in public /state.

              Close Burning Bush

              End the private Burning Bush session for one agent. Future thinks will no longer include the thread.

              Merovingian Bargain

              Offer a timed deal: if the agent meets a success condition, grant a reward; on failure or expiry, apply a punishment. Auto-settles each tick; manual settle overrides.

              Bargain settle (manual)

              Force an open bargain to succeed or fail immediately. Tick auto-settle is the normal path; use this to override.

              Anoint (private destiny)

              Mark an agent with a private destiny (think prompt only), public stigmata neighbors can see, and timed oracle hints revealed at set frames. Never in public /state.

              Revoke anoint

              Clear an active anointment — destiny, stigmata, and pending oracle hints — for one agent.

              Identity

              Identity edit

              Change persona, personality, and/or role for one agent. Timed edits restore on expiry; use Cancel identity forge to restore early.

              Identity copy overwrite

              Gradually blend the target's persona and personality toward a source agent each think. Optionally sync up to three memories from the source.

              Cancel identity forge (IRREVERSIBLE restore)

              Restore the identity snapshot taken when the active edit or copy was applied. Ends the forge immediately.

              Zones

              Architect zone

              Define a grid zone: paint terrain, place a keyed door barrier, or park agents in limbo. Enter cells as coordinates or bounds JSON — no canvas painting in the UI.

              Cancel architect zone

              Cancel an architect zone by intervention id. Reverts reversible paint and releases limbo holds tied to that zone.

              Release limbo hold

              Release agents parked in limbo for an active limbo zone. Leave agents blank to release everyone held by that zone.

              Reload

              Create checkpoint

              Save a labeled on-disk snapshot of the world and memory store (max 5). Safe while paused; oldest can be replaced when at cap.

              Restore checkpoint (IRREVERSIBLE)

              Replace the entire live world with a checkpoint snapshot. Irreversible except by restoring a different checkpoint.

              Restoring replaces the entire live world with the checkpoint snapshot. This cannot be undone except by restoring a different checkpoint.
